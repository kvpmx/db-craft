Create your account and build a small shop schema, from the first table to a saved diagram and SQL
file.

## What DB Craft does

DB Craft is a visual database schema designer. A project contains tables, fields, relationships, and
the layout of your diagram. Notes and colored groups explain the design. You can work privately,
publish a read-only diagram, or collaborate inside a team. The AI assistant can explain your schema
and propose changes for you to review.

The diagram describes a database structure. Editing it does not execute SQL against a running
database or store your application's customer records. You export SQL when you are ready to work in
your own database tools.

## Create an account

1. Open [Sign up](/register) from the login screen.
2. Enter your first name, last name, email address, and a password with at least **eight
   characters**.
3. Select **Sign up**. Follow the confirmation instructions sent to your email before signing in.
4. Open [Login](/login) and enter your email and password. **Login with Google** is also available
   on that screen.

The tutorial is public: you can read it before creating an account. Your profile menu contains
**Settings**, **Tutorial**, and **Sign out**. Save work before signing out.

## Create your first project

1. Open **Projects** and select **New project**.
2. Enter a descriptive name, such as `Shop schema`.
3. Choose **Private** for your own workspace, or **Public** if you want a shareable, read-only link.
   Check the selected visibility before submitting.
4. Choose MySQL, PostgreSQL, SQL Server, SQLite, MariaDB, or Oracle. The choice controls the
   available field types and SQL output.
5. Select **Create diagram**. The editor opens automatically.

::tutorial-media{src='/tutorial/media/new-project.png' alt='New project form with a name, visibility choice, and database engines'}
::

For this guide, use **PostgreSQL**. Create team diagrams from a team's page; those projects are
private to the team and use team permissions. See [Projects and visibility](/tutorial/projects).

## Build the shop example

1. In the **Tables** panel, select **New table**. A table appears with an `id` primary key.
2. Hover over its name in the sidebar and use the pencil to rename it `customers`. Confirm with the
   check mark or Enter.
3. Expand the table and select **Add field**. Change the new field name to `email` and choose
   `varchar` from the type selector. In its options menu, select **Unique**.
4. Add a second table named `orders`. Keep its `id` field and add `customer_id` with type `integer`.
5. Position the two tables by dragging their headers on the canvas.
6. Open the **Relations** tab and choose **New relation**. Set the source to `orders.customer_id`
   and the target to `customers.id`. This makes the foreign key point to the customer.
7. For the business meaning “one customer can have zero or many orders”, set the source end to
   **Zero or many** and the target end to **One and only one**.
8. Save the relationship, then select **Save** in the editor header for a personal project.

::

## Check your work

A relationship line should connect `orders.customer_id` to `customers.id`. Select the small expand
icon in a table’s canvas header to find it in the sidebar. Use the bottom-left **Fit view** control
if a table is outside the visible area.

Open **Export as SQL** in the header on a wide screen. Review the generated table definitions and
the foreign key direction, then copy the SQL or download the `.sql` file. Exporting does not replace
saving your diagram.
