Look up keyboard controls and resolve common issues with editing, saving, invitations, sharing, and
export.

## Keyboard and pointer reference

| Context                               | Action       | Result                                                          |
| ------------------------------------- | ------------ | --------------------------------------------------------------- |
| Editable canvas, outside a text field | Ctrl+Z       | Undo a recent change                                            |
| Editable canvas, outside a text field | Ctrl+Y       | Redo an undone change                                           |
| Selected relationship, note, or group | Delete       | Remove the selected object; use table controls to delete tables |
| Table rename input                    | Enter        | Confirm the table name                                          |
| AI message composer                   | Enter        | Send the message                                                |
| AI message composer                   | Shift+Enter  | Insert a line break                                             |
| Canvas stacking menu                  | Escape       | Close the menu                                                  |
| Canvas object                         | Right-click  | Open Bring to front / Send to back                              |
| Project name on a wide screen         | Double-click | Rename the diagram                                              |
| Expand icon in a canvas table header  | Click        | Open/select the corresponding table in the sidebar              |
| Empty canvas                          | Drag         | Pan the view                                                    |

Canvas undo uses Control, including on macOS. Ctrl+S / Command+S is not registered as an application
save shortcut; use the Save button. Avoid pressing Delete while a canvas object is selected and you
are typing elsewhere: the current deletion handler is global to the canvas page. Deselect objects
before editing text if necessary.

## I cannot edit a diagram

Check which page you opened. Public share links are always read-only. A team Viewer role cannot
edit; ask an admin for Editor access. A team diagram also waits for collaboration to become ready.
If you have edit permission and a live connection but cannot drag objects, check the canvas
lock/unlock control.

Private diagrams require the appropriate signed-in account. Missing team membership, deleted
projects, and invalid links can result in a not-found page.

## I cannot find a table or project

Clear the current search filter. Project search checks names only within the selected workspace, and
table search checks table names rather than all field names. Confirm that you opened personal
Projects or the correct team. Use Fit view or the minimap if a canvas object is outside the
viewport. Use the table's Fit to screen action to locate one table.

## A field option is disabled

Primary keys cannot be nullable. Auto increment requires a non-nullable primary key. Unique is
disabled when Primary key is already selected. Disable conflicting options in the appropriate order;
for example, turn off Auto increment and Primary key before enabling Nullable. Type selection alone
does not guarantee valid auto-increment syntax for every engine.

## A relation is wrong or cannot be created

You need fields in two different tables; self-relations are not supported. Open the relation form to
check both endpoints. The source is the foreign key and the target is the referenced key. Reversing
them changes the generated SQL. Cardinality defaults may need adjustment after a drag connection. If
a line disappeared after a deletion, it may have depended on the removed field or table.

If labels and markers are missing, check Show relation cardinality in Settings. If a relation's
business rules do not match the generated SQL, explicitly review field nullability, uniqueness, and
foreign keys; cardinality is descriptive.

## My work is unsaved or the team is offline

Personal projects need Save; SQL download and Commit version do not save the current personal
diagram. In a team, wait for Saved in addition to a live connection. Keep the tab open during
network interruptions and retry saving after reconnecting. Refreshing or closing the browser can
discard pending local changes. Use a version checkpoint for milestone recovery.

Rollback restores schema data, not a deleted project or team. Commit the current schema before
restoring an older version if you need both states.

## An invitation does not work

Check the code with the admin. Codes are case-insensitive after normalization, but a regenerated
code replaces the earlier one. Sign in with the invited email address. A code generated for several
emails does not allow unrelated accounts to join. Expired invitations may need replacement;
regenerating a code alone does not renew its expiration. Pending membership is not active membership
until the invitation is accepted.

## Export, Share, or rename is missing

Use a wider browser window: SQL export and Share are hidden below the large-screen toolbar
breakpoint, and the centered project title is hidden on small screens. Share appears only for public
projects. The public viewer does not have the full editing header. Editor history and AI also
require edit permission.

If copying a share URL or SQL fails, check browser clipboard permission. The share URL can be
selected directly, and SQL can be downloaded as a file. Review the engine and the script before use;
a type being available in the picker does not mean its full database-specific configuration has been
generated.

## The AI response failed or changed too much

Check the displayed error and your connection, then try a more specific prompt. A proposal changes
the diagram only when you apply it. Use Ctrl+Z or a prior schema version if the result is
unsuitable. Clearing chat does not undo an applied proposal. Ask for a new proposal if teammates
have edited the schema since the original was generated.

## Tutorial navigation and media

Use the search field to search article titles and full article text. Multiple words narrow the
results to articles containing all of them. Select a result to open it; Clear search returns to the
page you were reading. Articles have section links and previous/next navigation. You can copy a
heading's link to share a particular explanation.

On smaller screens, the menu button opens the article list and On this page expands the local
outline. Screenshots open at full size when selected. Videos use native player controls, do not
autoplay, and include English captions that you can toggle in the player. Screenshots and recordings
show the English interface, with captions and written instructions. Each recording also has a text
walkthrough underneath it so you can follow the steps without playing media.
