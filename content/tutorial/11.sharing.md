Publish a read-only view of a public diagram, copy its link, and understand the difference from team
access.

## Create a shareable diagram

Choose **Public** when creating a personal project. Public diagrams show a **Share** action in the
editor header on wide screens. Private diagrams do not show this action. Team diagrams are created
private and are shared with active members through the team workspace.

The current interface has no visibility switch for an existing diagram and no share-link rotation
button. Choose the visibility deliberately at creation. A public link should only be used for
diagram content you intend recipients to see, including notes and groups.

## Copy and open the link

1. Open your public personal diagram.
2. Save your changes so the viewer can load the latest persisted schema.
3. Select **Share** in the header.
4. Copy the URL using the copy button in the Share link dialog.
5. Give the URL to your recipients. Test it in a separate signed-out browser window if you want to
   check the recipient experience.

::tutorial-media{src='/tutorial/media/share-dialog.png' alt='Share link dialog with the copy control'}
::

The link uses the diagram's share identifier. Visitors do not need a DB Craft account to open it.
They see the canvas, including tables, relationships, notes, and groups, and can use pan, zoom, fit,
and the minimap to explore.

## What recipients can do

The shared page is read-only. It does not show the full editor header and sidebar, provide AI chat,
or allow edits, save, rollback, or team administration. The shared page does not expose the
authenticated SQL export dialog either. If recipients need to edit, use a team diagram and invite
them with an appropriate role.

The public viewer loads the saved schema. It is not a live collaboration session and does not stream
the owner's ongoing edits. Ask viewers to reload after you save an update.

## Access and troubleshooting

If a link is unavailable, check that it was copied in full and that the underlying project is still
public and still exists. A private project ID URL is not a substitute for the public share URL.
Signing in does not make a deleted share link valid.

Anyone with a working public link can inspect its visible schema. The current UI does not provide
password protection, a configurable expiration, or per-recipient access for public links. For
controlled account-based access, create the design in a team workspace with Viewer roles. Deleting a
public project removes its shared view too, but also deletes the project itself.
